# # Intelligent Traffic Management Using AI

## Project Overview
This project is a simple AI-based Intelligent Traffic Management System built using Python and Pandas.  
It analyzes traffic data such as vehicle count, average speed, signal time, and congestion level to provide smart signal timing suggestions and congestion prediction.

## Features
- Traffic data analysis using CSV dataset
- Congestion level count analysis
- Average vehicle count analysis by day
- Smart traffic signal timing suggestion
- Congestion level prediction using rule-based AI logic
- Accuracy calculation for predicted congestion

## Technologies Used
- Python
- Pandas
- CSV Dataset
- Rule-based AI logic

## Dataset Columns
- `time_of_day`
- `day_of_week`
- `vehicle_count`
- `avg_speed`
- `signal_time`
- `congestion_level`

## Working of the Project
1. Load traffic data from CSV file
2. Analyze traffic conditions
3. Suggest optimized signal timing based on vehicle count
4. Predict congestion level based on vehicle count and speed
5. Compare predicted congestion with actual congestion
6. Display project accuracy

- Accuracy of traffic prediction shown
